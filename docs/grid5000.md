# Running on Grid'5000

Grid'5000 is for approved research and education only; read the
[usage policy](https://www.grid5000.fr/w/Grid5000%3AUsagePolicy) first.

## One-time setup on a site frontend

```bash
ssh nancy
git clone https://github.com/NoeFlandre/benchmark-llms-landuse-relevance.git
cd benchmark-llms-landuse-relevance
curl -LsSf https://astral.sh/uv/install.sh | sh
```

The frontend is for checkout, submission, and monitoring only. Everything heavy runs
on a reserved node.

## Submit

```bash
usagepolicycheck -t
scripts/g5k_submit.sh 4:00     # one GPU, four hours: every rostered run
oarstat -u
```

To run only the LFM2.5-VL-3B runs (Transformers, SGLang baseline, SGLang + DSpark):

```bash
LRB_ONLY='LFM2.5-VL-3B' scripts/g5k_submit.sh 1:00
```

`LRB_ONLY` is a regex over run names (`lrb models` lists them) and `LRB_RUNTIMES`
restricts the runtimes (`transformers`, `sglang`); the submit script forwards these,
`LRB_MAX_NEW_TOKENS` and `LRB_BATCH_SIZE` to the node, since `oarsub` does not. The
budget defaults to the published 4096 tokens everywhere.

The SGLang runs need a recent NVIDIA GPU (the DSpark cards measure on an H100 and use
the FlashInfer attention backend); ask for an Ampere or newer card if the site mixes
generations, e.g.
`LRB_OAR_PROPERTIES="gpu_model LIKE 'A100%' OR gpu_model LIKE 'H100%'" scripts/g5k_submit.sh 4:00`.
Speed is only comparable between runs from the same job on the same node.

`scripts/g5k_node_run.sh` runs on the node: it syncs the pinned `inference`
environment and benchmarks each Transformers run, then re-syncs the `speculative`
(SGLang) environment and benchmarks each SGLang run — SGLang pins its own torch, so
the two cannot share one environment. Each run is writing `results/<namespace>__<model>.json`
as soon as that model finishes. Re-running the job skips models whose result file is
already present, so a walltime overrun is resumed rather than repeated.

The Hugging Face cache lives on node-local `/tmp` scratch (`HF_HOME`), which is wiped
between jobs — weights are re-fetched, results are not.

## Collect and publish

`/home` is site-local, quota-limited, and not backed up, so results leave Grid'5000
as soon as the job ends:

```bash
scp -r nancy:benchmark-llms-landuse-relevance/results ./results
uv run lrb report --results-dir results   # scores, speed, DSpark lossless check
uv run lrb publish NoeFlandre/benchmark-llms-landuse-relevance --results-dir results
```

Then release anything still held:

```bash
oardel JOB_ID     # only if the job is still running
usagepolicycheck -t
```
